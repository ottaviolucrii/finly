# Finly - Financial Intelligence System

**Finly** is a personal and business finance manager built with **Flutter** and **Supabase**. One login gives access to two isolated workspaces - **Personal (CPF)** and **Business (CNPJ)** - with accounts, credit cards, budgets, recurring bills, a dashboard with charts and alerts, reports, reminders, and more on the way.

## Architecture in one paragraph

Clean Architecture, feature-first. `presentation` (Cubit/BLoC) -> `domain` (entities, use cases, repository interfaces, pure Dart) <- `data` (Supabase). Errors are values (`Either<Failure, T>` with `dartz`), and the data layer catches everything, so a bug shows a retry button, never a frozen screen. Money is an integer number of cents. The database enforces isolation and integrity itself (RLS, constraints, triggers, RPC functions), so a bug in the app cannot leak or corrupt data.

## What works today

* **Dual workspaces** with a protected switch (a tap, the phone's biometrics or PIN, or the password) and strict data isolation
* **Accounts and credit cards** with automatic invoices, installments, invoice payment, editing and archiving
* **Transactions and transfers** (pending/posted, search, filters including period, pagination, delete with undo, owner withdrawals between workspaces)
* **Trash:** deleted transactions and transfers stay 30 days and can be restored
* **Categories, budgets** (with versions) **and recurring bills** (edit, pause, delete; generated by a daily job too)
* **Dashboard** with balance, month summary, charts (income vs expenses, spending by category), budgets, upcoming items and an "Atenção" card for budgets near the limit and bills overdue or due soon
* **Monthly report** with the month before beside it, and a CSV export that opens correctly in Excel and Google Sheets
* **Reminders:** local notifications at 9h for pending bills and card invoices that are about to be due, even with the app closed
* **Account security:** session lock with biometrics or PIN and a password fallback, brute-force limit, change password, forgot password by e-mail code, sign out of all devices, delete account
* **Brazilian specifics:** CPF and CNPJ (including alphanumeric CNPJ) validated by check digits

On the roadmap: offline mode, push notifications, forecast, yield simulator, tax reserve, receipt OCR, import and PDF export.

## Getting started

Create `env.json` (git-ignored) in the project root:

```json
{
  "SUPABASE_URL": "https://<project>.supabase.co",
  "SUPABASE_ANON_KEY": "<anon key>"
}
```

```bash
flutter pub get
flutter run --dart-define-from-file=env.json
flutter analyze
flutter test
```

Database: apply `sql/00` to `sql/14` in the Supabase SQL editor (see `docs/DATABASE.md`), then follow `docs/SUPABASE_SETUP.md`. Check the rules locally with:

```bash
pip install pgserver "psycopg[binary]"
python sql/tests/run_db_tests.py
```

The embedded Postgres has no time zone database on Windows, so on Windows rely on CI for this check.

### Android notes

* Biometrics: `MainActivity` extends `FlutterFragmentActivity` and the manifest has `USE_BIOMETRIC`.
* Reminders: core library desugaring is on in `android/app/build.gradle.kts`, and the manifest declares the permissions and the scheduled-notification receivers.
* On Xiaomi/HyperOS, set Autostart on and the battery to "No restrictions" for Finly, or the system may swallow the reminders.
* Flutter version: CI uses the same version as the development machine (see `.github/workflows/ci.yml`); change both together.
